# سرویس داخلی ساخت گروه از کارهای موجود — غیرفعال برای استفادهٔ واقعی

این مرحله کتابخانهٔ داخلی و آزمون‌های شبیه‌سازی‌شده را اضافه می‌کند. هیچ API یا دکمه‌ای به آن متصل نیست و اعمال پچ هیچ گروهی ایجاد نمی‌کند. **به این سرویس مسیر عمومی وصل نکنید و آن را روی دیتابیس واقعی فراخوانی نکنید**؛ ویرایش کار، پیگیری، مدیریت عضویت، خروج/انحلال، استثناها، کنترل تداخل سراسری و رابط کاربری باید ابتدا به‌صورت کامل گروه‌آگاه و آزمایش شوند. ساخت گروه با SQL دستی نیز مجاز نیست.

## قرارداد داخلی

- `previewGroupCreation({ selectedTaskIds, referenceTaskId })` یک تراکنش فقط‌خواندنی از لحاظ داده ایجاد می‌کند، قفل زمان‌بندی می‌گیرد و اطلاعات معتبر را از دیتابیس می‌خواند. خروجی planner مرحلهٔ قبل و `previewHash` را برمی‌گرداند. در شرایط مسدود، هش null است.
- `createTaskGroup({ selectedTaskIds, referenceTaskId, title, requestId, expectedPreviewHash })` فقط برای اتصال آینده است. انتخاب و شناسه و عنوان اعتبارسنجی می‌شوند. کارها، ردیف‌های زمان و تاریخچهٔ عضویت با ترتیب TaskID و قفل مناسب و روی یک اتصال تراکنشی خوانده می‌شوند. هش شامل طرح نرمال‌شده، شناسهٔ ردیف زمان و شناسه/نسخهٔ تمام عضویت‌های جاری و تاریخی است تا جایگزینی ردیف و ورود/خروج بین پیش‌نمایش و ذخیره تشخیص داده شوند.
- این مرحله فقط زمانی اجازهٔ نوشتن گروه می‌دهد که زمان‌بندی همهٔ اعضا از قبل یکسان باشد. همسان‌سازی زمان‌های متفاوت، انتخاب و تأیید صریح مرجع و بررسی تداخل با بقیهٔ کارها هنوز پیاده نشده است؛ سرویس آن را رد می‌کند. اجرای تست با دوبل به معنی مجوز استفادهٔ واقعی حتی در حالت زمان‌های یکسان نیست.
- در نوشتن تازه، گروه، اعضا و رسید idempotency در یک تراکنش ایجاد می‌شوند؛ هیچ وضعیت، زمان‌بندی، شرح یا پیگیری تغییر نمی‌کند. در هر خطا همهٔ نوشتن‌ها rollback می‌شوند. RequestID یکسان با محتوای یکسان رسید قبلی را بازمی‌گرداند؛ استفادهٔ متفاوت از همان شناسه رد می‌شود. نسخهٔ گروه در رسید متعلق به زمان اجرای عملیات است و لزوماً نسخهٔ فعلی نیست.
- قرارداد قفل در برابر مسیرهایی است که همان قفل را رعایت می‌کنند؛ اتصال‌های قدیمی یا تغییر مستقیم SQL که آن را رعایت نکنند با قفل برنامه به‌تنهایی محافظت نمی‌شوند. قیود، rollback و هم‌زمانی باید با SQL Server آزمایشی واقعی جداگانه تأیید شوند. این سرویس جایگزین کنترل مجوز کاربران در استقرار نیست.

## آزمون

`node --experimental-vm-modules --test tests/task-group-creation-service.test.mjs`

ماژول‌های واقعی برنامه با SQL و تراکنش شبیه‌سازی‌شده اجرا می‌شوند. آزمون‌ها واقعاً به SQL Server یا مرورگر وصل نمی‌شوند. تا آماده‌شدن راهکار کامل، از برنامه انتظار ساخت یا نمایش گروه نداشته باشید.
