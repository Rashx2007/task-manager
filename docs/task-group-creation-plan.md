# پیش‌نمایش ساخت گروه از کارهای موجود — مرحلهٔ داخلی

این مرحله فقط یک محاسبهٔ خالص و آزمون‌های آن است. هیچ API، دکمه، گروه، عضویت یا نوشتن دیتابیس ایجاد نمی‌کند و مهاجرت جدید ندارد. برای تست دستی گروه یا عضو با SQL نسازید. قابلیت گروهی هنوز برای استفادهٔ نهایی آماده نیست.

`planGroupCreation` ورودی را فقط باید از خوانندهٔ قابل‌اعتماد سمت سرور دریافت کند، نه از snapshot ارسالی مرورگر. انتخاب ۲ تا ۲۵۰ کار متفاوت و یک کار مرجع صریح لازم است. کار تکمیل‌شده، وضعیت نامعتبر، عضویت جاری، نبود یا تعدد رکورد زمان، مغایرت زمان کار با رکورد TimeDate و زمان/اولویت/مدت نامعتبر مانع هستند. در انتخاب معتبر، پیش‌نمایش مقدار قبل و بعد هر عضو را با زمان مرجع مشخص می‌کند؛ تغییر هر زمان یا اولویت تأیید صریح می‌خواهد. هیچ زمان یا تاریخچه‌ای اینجا تغییر نمی‌کند.

این پیش‌نمایش به‌تنهایی مجوز نوشتن نیست: مسیر آتی باید همهٔ داده‌ها را در همان تراکنش و زیر قفل زمان‌بندی دوباره بخواند، تغییر هم‌زمان را رد کند، تداخل زمانی با کارهای دیگر را بررسی کند، تأیید صریح را کنترل کند، membership را با قید یکتا و idempotency ثبت کند و هر خطا را کامل rollback کند. مدیریت عضویت، خروج و انحلال، استثنای موقت، رابط گروه، انتشار پیگیری و مسیرهای وضعیت هنوز نیازمند اتصال و آزمون‌اند. افزودن عضو یا بازگشت از استثنا نباید سوابق قدیمی را خودکار کپی کند.

آزمون: `node --test tests/task-group-creation-plan.test.mjs`؛ این آزمون محاسبات جاوااسکریپت را بررسی می‌کند، نه SQL Server واقعی یا مرورگر.
